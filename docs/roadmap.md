# ハツミル - Roadmap

## 現在地（MVP段階）

- [x] トップページ公開（`/`）— サービス紹介
- [x] MVPプロトタイプ公開（`/mvp/`）— 今日のはじめてフィード、レーダーチャート、CPリアクション
- [x] Supabaseスキーマ設計（`creators` / `milestones` / `reactions`）
- [ ] GitHub Pages有効化
- [ ] Supabase接続（現在はダミーデータのみ）

## 次のフェーズ

1. **Supabase接続**
   MVPのフロントエンドを、実際のSupabaseテーブルに接続する。
2. **登録機能**
   活動者自身がプロフィール・レーダーチャート軸を登録できるようにする。
3. **検索・マッチング機能**
   相性ベースの検索を実装する。
4. **本番アプリへの統合**
   `/mvp/` の役目を終えたら `/app/` として本番アプリに置き換える。

## URL運用方針

- `study-navi.github.io/hatsumiru/` … 常にサービス紹介（最新のトップページ）
- `study-navi.github.io/hatsumiru/mvp/` … 常に最新のプロトタイプ
- 将来的に `study-navi.github.io/hatsumiru/app/` … 本番アプリ

URLを固定したまま中身だけ更新していく運用とする（他プロジェクトと同じ方針）。

- 収益モデルの詳細設計
